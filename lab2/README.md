## Частина 1. В-дерево (коротко, для захисту)

Збалансоване дерево пошуку для ключів-раціональних чисел з параметром `t`
(мінімальний степінь, `t ≥ 2`):

- кожен вузол, крім кореня, містить від `t−1` до `2t−1` ключів;
- внутрішній вузол з `n` ключами має `n+1` дітей; ключі вузла розділяють діапазони дітей;
- **усі листки на одній глибині** — дерево ідеально збалансоване за висотою;
- висота `h ≤ log_t((n+1)/2)`, всі операції — `O(t·log_t n)`.

**Вставка** — за один прохід униз: повні вузли (`2t−1` ключів) розщеплюються
випереджувально, медіана піднімається в батька; якщо повний корінь — висота зростає на 1.

**Видалення** (CLRS, 3 випадки) — теж за один прохід униз; перед спуском у дитину
з `t−1` ключами вона поповнюється (позичання у сусіда або злиття), тому рекурсія
ніколи не повертається назад:
1. ключ у листку — просто видаляється;
2. ключ у внутрішньому вузлі — заміна попередником/наступником або злиття дітей;
3. ключа немає у вузлі — спуск у відповідну дитину з попереднім поповненням.

## Частина 2. Дерево відрізків на основі червоно-чорного дерева

Interval tree (CLRS, розд. 14.3) — **доповнена структура даних** поверх
червоно-чорного дерева. Зберігає відрізки `[low; high]` з раціональними кінцями:

- ключ вузла — лівий кінець `low`;
- додаткове поле `max` — найбільший правий кінець відрізка у піддереві;
- відрізки `[a;b]` і `[c;d]` перетинаються ⇔ `a ≤ d` і `c ≤ b`.

Підтримка `max` не псує асимптотику (теорема про доповнення ЧЧ-дерева):
- при вставці `max` оновлюється на шляху спуску;
- при поворотах перераховується лише для двох вузлів, що повернулись;
- при видаленні перераховується вздовж шляху від місця зміни до кореня — `O(log n)`.

**Операції** (усі `O(log n)`, бо висота ЧЧ-дерева `O(log n)`):
- `insert` / `remove` — звичайні RB-INSERT / RB-DELETE з підтримкою `max`;
- `findOverlap` (INTERVAL-SEARCH) — пошук будь-якого відрізка, що перетинає запит:
  якщо `max` лівого піддерева ≥ `low` запиту, перетин (якщо існує) гарантовано
  є ліворуч, інакше — тільки праворуч;
- `findAllOverlaps` — усі перетини за `O(k + log n)` з відсіканням за `max`.

## Самотестування

`main.cpp` містить стрес-тести: В-дерево звіряється зі `std::set` (обхід, пошук,
видалення) із перевіркою всіх інваріантів; дерево відрізків звіряється з повним
перебором на 2000 випадкових запитах із перевіркою властивостей ЧЧ-дерева та поля `max`.
